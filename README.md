# 🚀 Praticando o Básico do JavaScript

> Repositório criado para consolidar e colocar em prática os conceitos fundamentais de JavaScript aprendidos durante o curso.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma série de exercícios e pequenos códigos desenvolvidos com o objetivo de fixar a sintaxe, lógica de programação e manipular os conceitos base da linguagem JavaScript.

Aqui você encontrará exemplos práticos de:
- Declaração de variáveis e tipos de dados
- Estruturas condicionais e tomadas de decisão
- Laços de repetição (loops)
- Manipulação de funções e escopo
- Estruturas de dados (Arrays e Objetos)

---

## 🛠️ Tecnologias Utilizadas

- **JavaScript
- **HTML 5
